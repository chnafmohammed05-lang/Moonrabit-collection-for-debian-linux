# Moonrabit Collection for Debian Linux

A Debian/Linux-friendly version of the Moonrabit collection, built and prepared for Linux users to enjoy it on Debian-based systems.

This project is based on the original work by DaFluffyPotato and has been compiled/organized for Linux users, especially Debian users.

## Overview

This repository is intended to make it easier to run the Moonrabit collection on Debian-based Linux systems.

## Features

- Linux-friendly setup
- Debian-focused instructions
- Simple project layout for running the game on Linux

## Requirements

Before running the project, make sure your system has:

- A Debian-based Linux distribution
- Required dependencies installed
- Permission to execute files from the project folder

## Installation

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. If needed, make the files executable:

```bash
chmod +x ./<file-name>
```

4. Run the project using the correct launcher or executable:

```bash
./<game-or-launcher>
```

If the project includes a script instead of a binary, run it with:

```bash
bash ./<script-name>
```

## Running on Debian Linux

This project is mainly designed for Debian and Debian-based distributions such as Ubuntu and Linux Mint.

If you encounter issues:

- Check whether the required dependencies are installed
- Use `chmod +x` on executable files
- Run commands from the project directory
